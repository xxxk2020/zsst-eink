# 功能与开源说明

纸上刷题是一款面向 Android 墨水屏设备的原生离线工具，围绕本地做题、材料阅读与学习记录提供完整流程。

## 功能

- 原生阅读、刷题、练习、答题卡与申论材料浏览。
- 本地 JSON / ZIP 导入、图片引用、原子写入与存储回收。
- 字体设置、收藏、归档、作答进度、备份与恢复。
- 原创几何图标、原创演示题、打包与回归工具。

本地文件读写通过系统文件选择器和应用私有目录完成。支持导入题库、配套图片与字体，保存作答、收藏和阅读位置，并通过进度备份在设备间转移学习记录。

## 授权

原创部分按根目录 MIT 许可证发布。AOSP 的电脑端测试源码为 Apache-2.0，Gradle Wrapper 保留上游许可。第三方声明与完整许可证随仓库保留。

示例题和图形由项目原创，图片可通过 `tools/generate_demo_image.py` 重现。导入内容的使用和再分发按内容提供者的授权处理。

## 后续贡献

欢迎改进阅读体验、题目格式兼容、存储可靠性和墨水屏适配。提交问题时请提供原创最小样例，并隐去个人作答和身份信息。贡献内容应附有明确的来源与授权，源码检查和回归工具可用于提交前核对。
